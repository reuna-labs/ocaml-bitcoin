## Historical note

Versions 1.0 through 3.0 of this project (2012-2023) were a Bitcoin Core
JSON-RPC client written by Dario Teixeira and contributors, distributed
under the GNU LGPL version 2.1 with the OCaml linking exception.

That code was removed in full before the 4.0 rewrite and is preserved at
the git tag `legacy/v3.0`. No part of it is carried forward into 4.0 or
later; all code from 4.0 onward is original work under the ISC licence
above.
